The current architecture

From one result to a reliable evaluation system.

The project now separates the completed MCQ study, the current open-ended measurement work, and the next training experiments.

  1. 01 · completed study2,000 MCQs

    Eight model configurations on the QA-level test; Qwen3-1.7B two-stage reached 74.3%.

  2. 02 · current packet11 OEQs

    67 required claims and 32 explicit failure checks spanning 11 reasoning constructs.

  3. 03 · diagnostics55 answers

    Five answerers in an exploratory run used to find grader and rubric failure modes—not to publish a ranking.

  4. 04 · training system28 tests

    Hash-scoped source prep, rollouts, judging, rewards, contamination checks, RAFT construction, and evaluation.

The honest boundary

What is verified.

Supported by this study
  • The original fine-tuning effect is real within its study.

    Two-stage training improved Qwen3-1.7B by 18.5 points over base on the 2,000-question MCQ test.

  • The current packet is internally valid.

    The open-ended evaluation passes all packet checks with 11 questions, 33 calibration cases, 14 sources, and 11 constructs.

  • The evaluation system catches its own failures.

    Repeated grading exposed an unstable grader and systematic threshold differences before a publication claim was made.

  • The RLAIF workflow is implemented.

    Focused tests cover source preparation, rollout, reward, contamination, packet validation, RAFT construction, and evaluation summaries.
